# Demonstration data licence

The supplier feeds and evaluation labels in `demo/` and `evaluation/` are fictional records
created specifically for this project. Names, identifiers, prices, and descriptions do not
represent a real supplier catalog.

These files are distributed under the repository's Apache License 2.0. Product names use
invented brands and generic goods. The GTIN values are syntactically valid test identifiers and
must not be used as real trade-item identifiers.
